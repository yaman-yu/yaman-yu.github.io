# Yaman Yu Personal Website

This is a lightweight static academic homepage designed for GitHub Pages.

## Design System

- Typography: IBM Plex Sans only, for a simpler and more mature faculty homepage.
- Theme color: UW purple `#4b2e83`, used sparingly for links and emphasis.
- Layout: clean faculty homepage with concise biography, research areas, recruiting note, publications, and news.
- Structure: intro, research, prospective students, selected publications, recent news, CV link.

## Deploy

For a GitHub Pages user site at `https://yaman-yu.github.io`, the repository must be owned by the `yaman-yu` GitHub user or organization and named:

```text
yaman-yu.github.io
```

If the repository is under the `yamanyume` account, GitHub Pages will normally publish it as a project site path instead.
